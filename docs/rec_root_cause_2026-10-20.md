# 原始Rec在UPA场景中的根因诊断与修复原型验证

日期：2026-10-20。分支：`codex/gu-leshem2012-rec-study`。

## 当前结论与研究边界

已否定“由ULA改为UPA必然导致原式失效”，也已排除“仅仅是小快拍或额外工程处理导致当前损失”。当前零失配场景下，二维谱积分形成的矩阵同时存在点源空间形状偏差和干扰/白噪声比例失真，期望排除域还会显著改变这些偏差。

根因分四层，不应混称为一个程序错误：严格原式二维迁移的谱积分模型偏差；旧static额外处理进一步改变谱峰与背景比例；离散CovFit候选的有限网格方向误差；动态场景中固定角域标签误删强干扰。各层分别有固定其他变量的干预证据，不能只凭一条较高SINR曲线推断。

已完成不读取真值的修复原型、动态场景公平比较与独立随机子流验证。细化7°候选在本次18个测试点的中位数、第5百分位和低于15 dB的观测比例上均优于所比较的ESP、WCO、DL及历史CovFit；详见第10节。这里的“更强、更稳”严格指这些已声明的统计指标，不代表全样本最坏情况、全分布随机占优或一般性最优。

此处18点均使用原默认源几何，不能推广为任意源来向下CovFit都有效。后续受控22点几何扫描及其反例单列于[固定UPA下的源几何敏感性实验](rec_geometry_study_2026-10-20.md)：只改变来向即可使原始Rec接近Oracle，也可使CovFit因分区错误或近邻候选分辨问题而退化。

**不能宣称的结论：**原始Gu–Leshem公式已被证明在任意UPA中准确恢复INCM、7°期望先验始终正确、所有极端失效已经消除，或已满足1 ms实时处理。最差周期仍有严重的身份分组错误，第11节给出不隐藏失败点的直接干预证据。下列真值干预仅用于定位根因，不计入修复原型成绩。

## 1. 复现入口与不变量

```matlab
startup;
r = runRecRootCauseStudy('smoke');
```

参数集中于`config.m`的`cfg.experiments.recRootCause`，不改既有实验配置。原始矩阵求积调用`uav.incm.guLeshem2012Rec`：无加载、无伪逆、无谱底扣除、无显式噪声项、无PSD修复及收缩。共用MVDR接口另行记录其数值加载；本文列举的精确矩阵对照均未触发该加载。

默认场景：3×3半波长UPA，期望方向[0°,−35°]，两个干扰[40°,−25°]及[−55°,−20°]；SNR=10 dB，INR均30 dB，噪声功率1。所有试验零抖动，名义与真实期望方向严格相同。

精确矩阵输入是诊断干预：

\[
\mathbf R_x=10\mathbf a_s\mathbf a_s^H+
1000\mathbf a_1\mathbf a_1^H+1000\mathbf a_2\mathbf a_2^H+\mathbf I.
\]

它直接移除有限样本误差，但并未把真实INCM替换成非Oracle算法输入。只有明确标记的分解对照读取真实干扰方向或真实INCM。

输出：`results/rec_root_cause/2026-10-20/root_cause.mat`及同名CSV。MAT保存配置、全部逐试次记录、精确输入、软件与Git脏状态元数据，以及本次实验和配置的源文本。重跑该诊断会覆盖这一独立目录的同名结果，不覆盖原有实验7—9结果。

## 2. 快拍不是唯一原因，INCM也不是与快拍数无关

同一最大长度QPSK/噪声实现取前缀，20个确定性独立子流配对，二维立体角网格201，排除半宽25°：

| L | 原式SINR中位数/dB | 试次间5%—95%分位/dB |
| ---: | ---: | ---: |
| 8 | 不适用：L<M导致SCM奇异 | 不使用加载或伪逆代替原式 |
| 16 | 10.089 | 7.866—15.872 |
| 32 | 10.157 | 8.057—13.583 |
| 64 | 9.793 | 8.060—11.570 |
| 256 | 9.595 | 9.081—10.007 |
| 1024 | 9.457 | 9.331—9.759 |
| 8192 | 9.510 | 9.345—9.625 |
| 精确总协方差 | 9.521 | 无样本随机性 |

分位范围不是中位数的置信区间。样本数增大使结果集中到有偏的总体极限，并不使这一重构自动等于真实INCM。小快拍偶然更高也不代表小快拍有稳定优势。“比SCM-MVDR更不敏感”不能改写成“INCM不受快拍数影响”。

这一零失配诊断还严格满足\(\mathbf w^H\mathbf a_s=1\)：期望输出功率固定为10。原式的噪声输出约0.1381、干扰泄漏约0.9785，Oracle则分别约0.1159和5.68×10⁻⁷。因此此处9.52 dB的主要损失是干扰抑制不足，不是期望方向被自消；不能把所有低SINR都解释成“SCM中含期望信号”。

| ---: | --- | --- | ---: |
| 0 | 否 | 否 | 9.521 |
| 0 | 否 | 是 | 8.001 |
| 0 | 是 | 否 | 9.225 |
| 0 | 是 | 是 | 9.154 |
| 0.01 | 否 | 否 | 5.390 |
| 0.01 | 否 | 是 | 5.287 |
| 0.01 | 是 | 否 | 7.200 |

加载量为比例乘SCM平均阵元功率。底座使用已知诊断噪声下的\((\sigma_n^2+d)/M\)，并非把混合谱中的噪声“真实分离”出来。此表隔离三个因素，不等同于逐项复现旧static：旧static还有方向余弦测度、具体网格、噪声估计与结构投影。因此不能用最后一行冒充旧static的精确输出。

删除期望分量后再对真实INCM计算原式，得到10.130 dB，也远低于Oracle19.361 dB。因此“总协方差中含有期望信号”不是当前全部损失的解释。

粗网格确实造成显著误差，但加密没有使结果趋近19.361 dB。两种测度定义了不同重构，不能说改用正确Jacobian就必然获得真实功率；立体角系列在排除边界附近仍有小幅求积变化。

## 5. 直接定位矩阵形状和相对功率两项损失

仅作诊断，将原式矩阵投影到已知真实干扰方向的点源模型：

\[
\mathbf R_{\rm model}=\widehat\beta\mathbf I+
\sum_{j=1}^2\widehat p_j\mathbf a_j\mathbf a_j^H,
\quad (\widehat\beta,\widehat{\mathbf p})\ge0,
\]

使其与原式输出的Frobenius距离最小。注意，拟合目标是**原式输出矩阵**，而非真实INCM或SCM；不加正则。由此定义确定的残差\(\mathbf E=\widehat{\mathbf R}_{\rm Rec}-\mathbf R_{\rm model}\)。

在立体角201网格中，残差相对范数约6.538%，拟合白噪声系数1.070，两个干扰系数之和仅4.548，真实之和为2000。全矩阵统一缩放不会改变MVDR权值，问题在于相对比例和形状，不是单纯总迹偏小。

### 5.1 固定模型功率，只缩放形状残差

输入\(\mathbf R_{\rm model}+t\mathbf E\)，保持期望参考、真实评价矩阵不变：

| t | SINR/dB |
| ---: | ---: |
| 0 | 16.410 |
| 0.25 | 14.692 |
| 0.5 | 12.811 |
| 0.75 | 11.063 |
| 1 | 9.521 |

同一路径从t=0到1矩阵均为两个PSD端点的凸组合，不需要特征值修复。原式中相对不大的形状残差，足以使真实干扰泄漏从0.1132增到0.9785，而噪声输出仅从0.1154增到0.1381。这是直接干预证据，不只是观察到NMSE大。

### 5.2 去掉残差后，只提高干扰项相对白噪声的强度

输入\(\widehat\beta\mathbf I+c\sum_j\widehat p_j\mathbf a_j\mathbf a_j^H\)：c=1、10、100、1000分别得到16.410、19.316、19.361、19.361 dB。这不是统一缩放矩阵，而是改变干扰/噪声比。说明在模型空间正确后，相对功率不足仍产生损失。

另以真实方向上的Capon峰高减去\(\sigma_n^2/M\)作为点源系数，得到19.361 dB。它证明此诊断中从点源模型恢复有效零陷是可能的，但使用真方向，因此不能作为不依赖真值的修复。

两个干预沿特定分解路径定位机制，不能将其收益当作互相独立、对所有场景可相加的误差预算；该投影残差也不等同于已识别每个谱点的物理来源。

### 5.3 保持谱积分总质量和矩阵总迹不变的额外对照

为了避免把投影收益误解成总功率变化，另将每个区外谱节点按阵列指纹相似性分给最近真实干扰，并将其超出纯噪声底的积分质量原封不动地叠加到该真实干扰指纹上。这只改变空间形状，保留总质量；底座矩阵保持原样。结果为17.055 dB，原式9.521 dB，两者矩阵总迹相同。

若再将底座替换为同总迹白噪声矩阵，得到18.221 dB；若只对白噪声底座做同迹白化而保留弥散干扰项，则仅为9.764 dB。说明当前主要损失不只是背景不白或总迹太小，弥散谱节点对应的空间指纹也是实质因素。该归属读取真实方向，不是盲分离方法，也不能给这些谱节点作物理噪声/干扰来源证明。

## 6. 为什么谱峰积分可能系统性低估点源功率

以下为本项目的单源解析推导，不是声称原论文给出了这一结论。设\(\mathbf R=\sigma^2\mathbf I+P\mathbf a_0\mathbf a_0^H\)，所有导向矢量范数为\(\sqrt M\)，令\(\kappa=|\mathbf a^H\mathbf a_0|^2/M^2\)。由矩阵求逆引理：

\[
P_C=\frac{\sigma^2}{M}\frac{\sigma^2+PM}{\sigma^2+PM(1-\kappa)}.
\]

峰顶为\(P+\sigma^2/M\)，但峰面积不等于P。若二维峰附近\(1-\kappa\approx\boldsymbol\delta^H\mathbf H\boldsymbol\delta\)，H正定，且局部测度光滑非零，令\(s=PM/\sigma^2\)，超出纯噪声底的局部贡献近似正比于：

\[
\int_0^r\frac{s\rho}{1+s\rho^2}\,d\rho
=\frac12\log(1+sr^2),
\]

而不是与s成正比。一维非退化峰的对应局部积分则具有\(\sqrt s\)阶增长。这个局部高信噪比分析不是多源、边界及全积分的完整定理，但说明“峰高近似功率”并不能推出“二维峰积分准确恢复点源功率”。阵列孔径、峰形、测度、排除边界会共同改变积分矩阵的结构。

当前实验中的高INR扫描仍用201网格，尚未对40/50 dB逐点做峰宽自适应收敛验证，因此不能拿它的高INR数值证明严格渐近规律。默认30 dB网格对照和上述矩阵干预才是当前主要实验证据。

## 7. UPA必然失效的反例

保持3×3半波长UPA、功率、25°排除半宽、原式和权值求解器不变，只将期望方向设为[0°,−90°]，干扰设为[0°,−48.189685°]及[90°,−48.189685°]。对应两个干扰的平面方向余弦为[2/3,0]及[0,2/3]，三个导向矢量正交。

立体角网格201、401、801分别得到18.759、18.756、18.766 dB，Oracle为19.542 dB。该反例直接否定“二维UPA必然导致原式失效”，但它不是替换默认场景以制造性能优势：只用于检验普遍性断言，不参与修复方法的性能排名。

另一个单元对照保持默认世界来向、功率和9个阵元，改为y轴1×9 ULA，按其可观测角\(\theta=\arcsin\xi_y\)在±90°内积分并排除名义投影方向周围25°，得到18.001388847 dB，未触发数值加载。它排除了“SNR或阵元数差异是唯一原因”，但线阵孔径和先验含义也改变了，不能据此声称已经隔离纯维度效应。公式手算测试与该控制的输出保存在`formula_controls_tests.log`。

同一默认源几何下，将阵列改为5×5、7×7，原式分别得到12.047、21.289 dB，各自Oracle23.763、26.901 dB。阵元数与孔径同时变化，且这里只使用201网格，不能把这些结果当作已隔离的“纯维度效应”或已收敛阵列规模定律。

## 8. 后续修复的验证门槛

1. 不再把“去掉加载”“网格加密”“换立体角”当作足以修复的方法；分别已有反证。
2. 检查不依赖真值的候选方向定位及点源功率模型能否消除已定位偏差。若改变估计器，必须另命名，不冒充原始Rec。
3. 在零失配之外，固定名义参考并量化真实期望响应损失，区分INCM估计和期望导向保护；若需改变权值接口，所有相关方法应公平对照。
4. 必须覆盖L=8、64及足够大的L。L=8的原式保持“不适用”，只能把加载变体另列，不能给原式虚构成绩。
5. 主默认几何不变，保留已有ESP/WCO参数，不因追求胜出而削弱基线；使用配对试次、独立验证随机实现、中位数、低分位及置信区间评价。
6. 先前参考FIG的INCM并非所有抖动点都最高，不能把“全范围支配”当作该历史图已经证明的事实。

## 9. 不使用真方向的修复原型及验证协议

### 9.1 先检验已有CovFit，不把它冒充原式

`runCovfitPopulationDiagnosis`完整交叉3种网格、3种加载、3种NMS半径与3种正则，共81点。精确协方差下，201网格、加载0.001、NMS半径0、正则0得到19.017 dB及约6.904×10⁻⁶的INCM NMSE；但部分正则5000设置也能达到更高SINR，尽管矩阵NMSE很大。再次说明较高SINR与功率准确不是同一判据。该扫描不是独立性能验证。

### 9.2 候选细化仅修正离网误差，不更新MVDR参考

在上述固定点源模型设置上单列`refined_candidate_covfit`。新增`refineCaponNodes`对已有候选求局部解：

\[
\min_{\boldsymbol\xi}\ \mathbf a(\boldsymbol\xi)^H\mathbf R_{\rm load}^{-1}\mathbf a(\boldsymbol\xi),
\quad \|\boldsymbol\xi\|_2\le1,
\quad \boldsymbol\xi\text{仍位于原候选的先验分区}.
\]

该目标一般非凸，使用局部SQP和解析目标梯度，不保证全局解。未成功或未改善目标的候选回退至原节点；细化后的近重复节点去重，再使用原有联合非负功率拟合。**不读取真实方向，不使用训练序列确认身份，不更换名义期望MVDR参考。** 既有`upaCovfit`的细化开关默认关闭，历史方法保持原定义。

另列`refined_narrow_sector`，只将上述变体的角域半宽从25°改为7°，其余不变。这是用于研究分区失效的独立对照，不能声称真实期望始终位于7°区域；在默认期望弱于干扰的场景中，候选相对阈值本身也可能帮助区分强干扰和弱期望。若未来改变SNR/INR关系，需要重新检验，不能把该分类当作普适身份识别。

### 9.3 当前开发与独立验证严格分开

`runRecRootCauseValidation`同时保留11项结果：Oracle、ESP、WCO、原式Rec、历史CovFit、未细化零正则候选、DL、旧static、真实INCM＋名义方向、细化25°候选、细化7°候选。

- 物理场景、基站几何与功率均不变；ESP保留原论文的3维子空间，WCO保留平方不确定半径0.3M，DL保留原配置。
- L=[8,64,256]；抖动RMS=[0,4,8,12,16,20]°；同一最大长度快拍取前缀，不同抖动点共享标准正态与信号/噪声实现。
- smoke为3独立试次×2周期，仅用于开发。preliminary为20独立试次×20周期，使用另一组子流，未将开发时的前三个试次混入验证。
- 先在线性域对每试次周期平均，再取独立试次中位数；另保留全部周期5%分位及低于15 dB的观测比例，避免只报告较高平均值。
- 配对bootstrap以独立试次为单位，同一抽样索引用于目标和基线，计算中位数之差的95%区间；这些是逐比较区间，未作全范围多重比较校正，不构成严格的全范围同时支配证明。
- 事后记录真实源是否违反原25°分区，及细化诊断，供解释失败点；不反馈算法。
- 每个完成试次保存检查点；MAT包括参数、原始逐周期指标、Git/软件元数据及相关源文本快照。运行警告不隐藏，数值求解可靠性仍须审计。

smoke的64快拍零抖动中，细化候选中位数约19.280 dB、Oracle19.361 dB。这只是开发结果；大抖动下即使真实INCM＋固定名义方向也可能出现深衰落。是否实现了“最强且稳定”必须以独立验证和失败点审计为准。

诊断绘图入口：`plotRecRootCauseValidation(resultFile,keepOpen,selectedNames)`。原生FIG、矢量PDF及PNG位于独立结果目录。中位数图的误差棒为试次级bootstrap 95%区间；周期低分位和中断比例图只显示相应样本统计量，不冒充置信区间。默认选择鲁棒基线与细化变体以检查修复效果；全部11种方法的原始数据不删除，亦可显式传入其他方法绘图。

## 10. 完整独立验证结果：不是只看有利曲线

完整`preliminary`已完成20独立试次×20周期，6个RMS点×3种快拍数，11个方法或诊断项。以下“扫描范围”是[0,4,8,12,16,20]°六个已测点，不外推成连续区间内任意角度的保证。

横轴\(\sigma\)表示三个轴各自的稳态RMS均设为\(\sigma\)，不是合成姿态偏差向量的RMS；后者为\(\sqrt3\sigma\)。因此20°是三轴各20°的压力条件，不能表述成真实UAV普遍具有这组参数。

### 10.1 实际表现最好的原型及数值

本轮最优统计结果对应`refined_narrow_sector`：Capon候选＋非负点源协方差拟合＋局部候选细化，7°角域；不是原始Rec，也不是Gu–Leshem的Rec+Est。MVDR参考始终是固定名义方向。期望标签候选也可局部细化，但只用于联合协方差拟合，其导向矢量不用于更新最终权值参考；没有实施原论文的Est步骤，也未使用训练序列身份判别、真实姿态或真实来向。

### 10.2 配对及同时比较审计

除原有逐点配对区间外，`auditRecSimultaneousComparison`将“细化7°候选对四个基线、全部3×6设置”的72项中位数比较定义为同一个比较族。500次重采样均以独立试次为单位，所有比较共享相同抽样索引，保留方法、快拍数与RMS之间的配对关系。

用bootstrap标准差标准化各比较误差，取跨比较最大绝对标准化误差的95%分位构造近似同时区间。72项区间下限均大于0，最小下限为0.476701 dB。该审计支持本设置中的中位数排序，但它是n=20、B=500下的有限样本bootstrap近似，不是严格覆盖率定理，不给第5百分位、最坏周期或所有未测参数提供同样的保证。

### 10.3 把离网误差与“拟合功率不对”进一步分开

`runCovfitDirectionOnlyControl`按每种L选取零抖动下已记录细化增益最大的点，仅用于放大症状。它固定原NNLS的每个干扰候选系数、噪声、候选数、身份标签与名义MVDR参考，只对干扰候选位置执行同一个不读取真值的局部Capon细化，不重估功率：

| L | 细化前/dB | 只细化方向、功率不变/dB | 完整细化原型/dB | 细化前拟合相对KKT残差 |
| ---: | ---: | ---: | ---: | ---: |
| 8 | 6.768 | 17.215 | 17.217 | 4.17×10⁻¹⁶ |
| 64 | 9.127 | 19.341 | 19.341 | 3.17×10⁻¹⁶ |
| 256 | 9.127 | 19.308 | 19.308 | 2.41×10⁻¹⁶ |

这几例的旧功率拟合已经满足数值最优性，且只改方向就恢复了几乎全部增益。因此不能把它们归因于“SCM有误差，所以功率拟合必然没用”或“求解器没有收敛”。这是诊断性选点，不可把表中增益当作平均性能；总体排序仍依据完整独立验证。

### 10.4 只缩小角域不能替代估计器修复

`runRawRecNarrowControl`重放完整验证的同一批快拍，仅将严格原式的排除半宽改为7°，不增加加载、谱底、噪声项或修复；所有可用点的权值数值加载也为0。

| L | RMS/° | 原式25°/dB | 原式7°/dB | 细化CovFit 7°/dB |
| ---: | ---: | ---: | ---: | ---: |
| 64 | 0 | 9.618 | 15.397 | 19.142 |
| 64 | 8 | 9.520 | 8.374 | 18.920 |
| 64 | 20 | 5.378 | 1.653 | 18.108 |
| 256 | 0 | 9.567 | 15.478 | 19.294 |
| 256 | 20 | 5.359 | 1.473 | 18.192 |

8快拍下两个原式均不适用。小角域只在零抖动时缓解了积分截断；动态场景中，期望方向移出角域后，原式仍积分其能量。故新原型的结果不是简单缩小排除域、却仍沿用原式的效果。

## 11. 极端失效仍存在，而且已经定位到具体步骤

### 11.1 不是所有意义下的“最稳定”

最优原型虽在上述中位数、第5百分位和失效比例上均领先，仍有少数比某些基线更深的极端失败；经验CDF会交叉。不能称其具有全分布随机占优、最坏情况最优或零失效保证。

在7°角域下，20° RMS的期望方向有91%的已测周期位于期望池外。它仍得到较好统计结果，**不是因为7°可靠包住了期望信号**，而是当前SNR=10 dB、INR=30/30 dB场景中，强干扰与弱期望的谱值差异配合相对门限，帮助避免将大部分弱期望候选纳入干扰模型。该性质依赖功率对比及候选规则，不能泛化到期望与干扰等强或角色互换的场景。

这里的分区概率均按算法采用的下半球方向余弦代表元计算，与实际候选筛选一致；不将平面阵的这一约定误称为已经获知真实三维射线身份。

12° RMS时，7°区域内仍出现了1%的强干扰误入周期；源身份标签来自角域，不能自动发现这一点。下表逐一重放每种L的最差周期，重放误差均为0：

| L | 最差周期SINR/dB | 真实INCM＋同一名义参考/dB | 仅放回误删干扰候选后的诊断SINR/dB |
| ---: | ---: | ---: | ---: |
| 8 | −61.080 | 15.985 | 15.177 |
| 64 | −31.601 | 15.794 | 15.350 |
| 256 | −31.602 | 15.794 | 15.797 |

最后一列是**Oracle身份重标记干预**：利用真值仅定位哪一个期望标签候选实际对应干扰，将其原有拟合功率与原有方向构成的项放回INCM；不重估方向、功率、噪声或MVDR参考。三个被误删候选与对应真实干扰的归一化指纹相似度分别约0.999971、0.999981、1.000000，拟合功率约968.5、837.4、958.6。

因此，这几例并非没有找到干扰或完全没估出其功率，而是**找到了强干扰，却根据固定角域标签把它删除了**。恢复同一项后SINR回升，是对删除步骤的直接因果干预。Oracle干预不计入算法成绩；不能把其结果说成当前原型已经具备身份识别能力，也不能将这类失效都简称为SCM中的“期望自消”。

### 11.2 计算时间边界

本次单计算线程MATLAB测得该原型平均约39 ms/周期，95%耗时约44—45 ms。它是性能与根因研究原型，不是已满足1 ms硬实时要求的实现；仿真处理周期与串行脚本耗时是两个不同量。不能将仿真中的逐周期更新写成已经完成实时部署。

### 11.3 已确认的研究范围与方向失配边界

2026-10-20，用户确认：**仍只研究INCM重构，明确记录方向失配的性能边界**。因此，当前研究不扩展为“INCM重构＋期望导向估计”，不实现Gu–Leshem的Est步骤，也不根据估计结果更新最终波束形成权值所用的期望参考导向矢量。原始Rec、历史方法和现有验证结果保持不变。

后续分析应明确区分以下两类损失：

1. **INCM重构侧的损失**：包括候选方向或功率估计不准、谱积分形状偏差，以及根据角域标签误删真实干扰等。第11.1节的极端失效属于这一类，不能用“固定期望方向失配”解释掉。
2. **固定名义期望方向的失配损失**：即使输入真实INCM，使用固定名义参考求得的MVDR权值也不保证真实期望响应保持不变；大抖动时仍可能出现深衰落。这是当前固定参考方案的性能边界，不能承诺仅靠更准确的INCM就能消除。

“真实INCM＋固定名义参考”只作为隔离第一类误差的诊断对照，**不是输出SINR上界**：存在方向失配时，某些有偏协方差估计反而可能得到更高的真实SINR。真正的Oracle上界仍是使用真实INCM和真实当期期望导向矢量的MVDR；它只用于评价，不向待比较算法提供真值。

现有原型中的期望标签候选允许局部细化，但只作为联合协方差拟合的待剔除分量，不用于更新最终权值参考。这与本次排除的“期望导向估计后修正波束权值”不同，不能混写为已实现Rec+Est。

若后续开展新任务，可在INCM重构范围内研究候选身份保持、分区可靠性及误删干扰的检测；任何新增信息或算法变化均需另行说明。本次确认只记录范围决定，没有自动新增算法或实验，也不通过更换随机种子、源功率或削弱基线来掩盖失败。
