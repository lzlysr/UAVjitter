# Gu–Leshem 2012 Rec复现、UPA迁移与协方差拟合诊断说明

## 1. 研究目的

本分支回答三个相互独立的问题：

1. Gu与Leshem（2012）原论文的Reconstruct（以下简称Rec）在论文的一维ULA场景中能否按原公式得到合理结果；
2. 同一公式不加改进地直接迁移到当前无人机矩形UPA场景后，性能变化来自哪里；
3. 独立命名的 `upa_covfit_incm`能否在不读取真值、不修改原始Rec和不削弱
   对照方法的前提下，稳定优于当前ESP、WCO和适用时的原始Rec。

因此，实验7是“原论文忠实复现”，实验8是“UPA直接迁移诊断”，实验9是
“UPA协方差拟合与双快拍验证”。实验8不是论文原有实验，也不是改进方法；
实验9保持独立名称，不能反向改写为原论文Rec的结论。

## 2. 原论文例1参数

文献参数集中在 `cfg.literature.guLeshem2012`：

- 阵列：10阵元ULA，阵元间距0.5波长；
- 名义期望方向：5°；
- 名义干扰方向：−50°和−20°；
- 两个干扰的INR：均为30 dB；
- 期望信号角域：`[0°,10°]`；离散求积在 `[-90°,0°]` 与 `[10°,90°]` 上构造，两个边界点只取梯形半权重；连续积分中有限个边界点不改变积分值；
- 实际期望和干扰DOA：每次蒙特卡洛试验分别在名义角附近±4°内均匀抽取，并在该试验的整块快拍内保持不变；
- SNR扫描：−30 dB至50 dB，步长5 dB，固定30快拍；
- 快拍扫描：10至100，步长10，固定输入SNR为20 dB；
- `paper`档采用论文报告的200次蒙特卡洛试验；`smoke`和`preliminary`只缩减试验次数与积分网格，用于代码检查和初步趋势观察。

期望、干扰和噪声均使用互相独立的零均值圆对称复高斯样本。这里与当前UAV主场景采用QPSK训练序列的设置不同，原因是实验7必须服从原论文的窄带随机信号仿真，而不是强行复用主场景波形。

## 3. Rec公式与代码边界

`uav.incm.guLeshem2012Rec`只完成两步：

1. 使用未加载样本协方差计算Capon谱：`1/(aᴴ R̂⁻¹ a)`；
2. 用配置传入的梯形求积权重，在期望角域补集上累加 `P(θ)a(θ)aᴴ(θ)`。

该函数故意不包含以下处理：

- 对角加载或伪逆；
- 显式添加噪声单位阵；
- Capon谱底座扣除或重新标定；
- Hermitian/PSD投影、特征值下限或收缩；
- 导向矢量再估计，即不实现论文的Rec-Est；
- 动态扇区、谱对齐、跨周期稀疏连续性或局部非均匀求积。

这些处理有些可能改善当前UPA场景性能，但它们不属于本次要求的原始Rec。把它们直接写入Rec会混淆“论文方法复现”和“后续改进”。由于原式直接求逆，配置要求所有ULA复现快拍数不小于阵元数；若协方差仍数值奇异，函数明确报错。

## 4. 对照方法

仅复用原论文实验中出现且本工程已经实现的方法：

- `oracle`：使用真实INCM和真实期望导向矢量的理想先验MVDR，仅作上界；
- `esp`：特征空间投影方法，信号子空间维数取3，对应一个期望信号与两个干扰；
- `wco`：最坏情况优化方法；论文给出的 `epsilon=0.3M`在当前求解器的范数半径接口中按 `sqrt(0.3M)`换算；
- `gu_leshem2012_rec`：新增的原始Rec重构后接标准MVDR。

`cfg.literature.guLeshem2012.methodNames`必须包含Rec，可按需要删减其他三个对照方法并调整顺序。DL-MVDR、普通静态INCM等即使工程已有，也因未满足“论文中同时出现”这一条件而不进入实验7和实验8。实验9固定运行Oracle、ESP、WCO、原始Rec和独立的UPA CovFit，以便保持统一索引和配对统计。

## 5. 实验7：ULA忠实复现

运行：

```matlab
startup;
cfg = config("smoke");
result = exp07_gu_leshem2012_reproduction(cfg);
```

结果包含SNR扫描与快拍扫描的逐试次线性SINR、Rec的INCM误差、各方法运行时间、线性域均值/中位数及其dB表示。图中的主统计量为“线性SINR蒙特卡洛均值转dB”，用于对应论文常见的平均输出SINR曲线；不能直接对逐试次dB做算术平均。

`smoke`结果只证明公式、场景和结果链可以执行。只有 `paper`档200次蒙特卡洛的趋势与论文图形一致，才能支持“完成原论文数值复现”的表述。

## 6. 实验8：UPA直接迁移诊断

运行：

```matlab
startup;
cfg = config("smoke");
result = exp08_gu_leshem2012_upa_transfer(cfg);
```

该实验使用当前 `3×3` UPA、世界坐标固定的期望/干扰方向、三轴姿态高斯—马尔可夫抖动和主场景快拍生成器。唯一公式迁移是：把一维DOA角度积分替换为二维方向余弦可见域内的面积求积，并排除名义期望方向附近的固定球面角域。

诊断指标及含义：

- 输出SINR：最终抗干扰性能；
- INCM归一化平方误差：整体矩阵估计偏差；
- 最大特征值比例：判断干扰功率尺度是否严重高估或低估；
- 归一化特征值谱误差：先把各自特征值除以总和，再判断相对能量结构是否错误；
- 估计INCM条件数：判断重构的干扰主模态与噪声底之间是否具有合理动态范围；
- 干扰子空间距离：判断主干扰空间方向是否重构错误；
- 期望移出排除区概率：姿态抖动是否使真实期望信号落入重构积分区；
- 干扰进入排除区概率：固定排除区是否误删真实干扰能量；
- 网格敏感性：二维面积积分是否随网格密度发生明显尺度变化。

若ULA复现良好而UPA迁移明显退化，应优先从二维积分测度、固定期望排除区与姿态造成的角域漂移、以及噪声/干扰功率尺度解释，不能把问题简单归咎于“INCM理论无效”。后续若要加入二维Jacobian、功率校准、动态扇区或结构约束，应另立改进方法名称，不能继续称为未经修改的 `gu_leshem2012_rec`。

## 7. 实验9：UPA协方差拟合与双快拍诊断

运行：

```matlab
startup;
cfg = config("preliminary");
cfg.plot.visible = false;
cfg.plot.closeAfterExport = true;
cfg.output.overwrite = true;
result = exp09_upa_incm_diagnosis(cfg);
```

`upa_covfit_incm`使用加载Capon谱提取期望区和干扰区候选方向，以非负
Hermitian协方差拟合估计候选功率，并只用干扰候选与独立噪声项重构INCM。
它不读取真实姿态、真实方向、真实干扰数或真实INCM。L=8时使用配置噪声
功率并标记 `configured-underdetermined`；L=64时使用样本协方差较小特征值
的中位数。原始 `uav.incm.guLeshem2012Rec`没有任何修改，L=8时保持
`singular-not-applicable`。

公共锁定参数为：

| 参数 | 数值 |
|---|---:|
| `loadingRatio` | 0.12 |
| `fitRegularization` | 5000 |
| `peakThresholdRatio` | 0.15 |
| `peakNmsRadiusBins` | 0 |
| `maximumCandidateCount` | 7 |

正式 `preliminary`实际运行20次配对试验；零抖动网格/测度分支每试次1周期，
动态分支每个抖动点20周期。快拍固定为 `[8,64]`，网格边长固定为
`[21,51,101,201]`，测度固定为 `direction_cosine`、`solid_angle`和
`az_el_solid_angle`，动态分支选择101×101的 `solid_angle`网格。正式相对
验收只取该101×101 `solid_angle`零抖动工作点及使用同一工作点的动态
0°/4°/8°；其余网格/测度组合只作诊断。

### 7.1 H1至H5的证据

- H1“二维峰面积造成相对功率偏差”：对原始Rec得到支持。L=64、
  `solid_angle`下，21/51/101/201网格的迹比分别为0.00138、0.00219、
  0.00226和0.00251，绝对尺度随加密仍远低于1；对应平均SINR为
  −0.102、4.631、9.906和9.602 dB，稳定在错误结果附近而不是逼近Oracle。
- H2“当前网格过粗”：网格对候选方向有明显影响，但“只需继续均匀加密即可
  单调收敛”的预测不成立。锁定CovFit在51/101网格的零抖动均值差为
  L=8的0.048 dB和L=64的1.231 dB。更直接的粗网格反例是：L=64、
  21×21网格三种测度下，CovFit−ESP配对差均值/中位数为
  −1.693/−1.877 dB，CovFit−WCO为−1.691/−1.584 dB。该方法仍然网格
  敏感；这些差异保留为诊断量，不属于主验收。
- H3“二维积分测度不正确”：测度是原始Rec退化的一部分，但不是充分修复。
  L=64、101网格下三种测度的Rec平均SINR为8.173、9.906和9.935 dB，
  迹比分别为0.00103、0.00226和0.00226；两种正确立体角离散结果接近，
  但仍显著低于19.361 dB的Oracle上界。
- H4“噪声底与动态范围失真”：对原始Rec得到支持。原始Rec没有显式噪声
  单位阵，迹比约千分之一级。CovFit显式建模噪声并能提高输出SINR，但锁定
  参数的零抖动迹比仅0.0535/0.0534、NMSE为0.8972/0.8970，说明它通过
  正则化获得稳定权值，并未准确恢复绝对协方差尺度。
- H5“固定期望排除区只在抖动后成为主要问题”：零抖动时完全否证其为首因。
  零抖动期望移出和干扰进入率均为0；动态0°/4°/8°的期望移出率仍全为0，
  最大干扰进入率为0、0.005和0.0375，只在高抖动时形成小概率次要因素。

## 8. 输出位置与结论边界

三个实验各自导出MAT、CSV、FIG、矢量PDF、PNG和JSON。结果文件保存完整配置、随机种子方案、逐试次原始值、运行环境和实际工作量。它们不加入 `run_all`，避免文献专项研究改变原有五组主实验的批处理合同。

推荐表述边界：

- `smoke`：只能写“完成原始Rec与两类场景的代码实现和运行链验证”；
- `preliminary`：可以写“观察到某种性能趋势”，但需同时报告试验次数；
- `paper`：在200次蒙特卡洛及论文曲线趋势一致后，才可写“复现了论文例1”；
- UPA迁移结果：只能用于分析直接扩展的适用性和问题来源，不能写成原论文已验证的结论。
- UPA CovFit结果：只能写“在本配置的20×20 preliminary中优于已比较的
  非Oracle鲁棒方法”，不能写成原论文结论、Oracle等价或一般性最优。

## 9. 当前验证快照（2026-08-30）

> 2026-10-20新增的精确协方差、工程因素交叉、矩阵干预及独立验证研究见[原式Rec根因诊断](rec_root_cause_2026-10-20.md)。下列历史结论保持其原有范围；新原型不等同于原论文Rec，也没有替换历史结果。

`preliminary`档20次蒙特卡洛的ULA实验中，在输入SNR为20 dB且固定30快拍时，理想先验MVDR的平均输出SINR为29.90 dB，Rec为28.47 dB，相差1.43 dB。独立的快拍扫描在 `K=30` 处得到29.93 dB和28.52 dB。两组独立随机实现给出一致量级，说明当前原始Rec实现至少在论文场景下没有复现出旧UPA代码的严重低SINR问题；但20次试验仍不足以替代论文的200次复现。

默认 `smoke` UPA迁移（3次试验、每次2周期、64快拍、21×21网格）中，三轴抖动RMS为0°、4°、8°时，理想先验MVDR平均输出SINR约为19.36、19.35、19.40 dB，而直接二维化Rec约为2.00、5.37、2.42 dB。Rec重构INCM的最大特征值只是真值的0.200%、0.089%、0.042%，归一化平方误差约为0.998、0.999、0.999；同时，去除整体尺度后的特征值谱误差仍约为0.466、0.318、0.322，估计INCM条件数中位数约为101、43、24。由于MVDR权值对协方差的统一正比例缩放不敏感，不能把低SINR仅归因于绝对功率尺度偏小；当前证据表明二维直接求积还改变了相对特征值结构和干扰/噪声动态范围。由于 `smoke`样本很少，这些数值只能作为后续积分测度、相对功率结构和扇区研究的定位证据，不能作为最终性能结论。
