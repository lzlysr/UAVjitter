# 经典方法参数筛选与锁定验证结果

> 历史结果说明：本文档记录的是2026-08-30方法替换之前的静态Capon均匀
> 积分INCM。当前代码中的 `static_incm_mvdr` 已改用UPA候选非负协方差
> 拟合，因此下列静态INCM参数和性能数值不得作为当前实现的结果引用。

## 实验目的与结论边界

本实验比较理想上界、DL-MVDR、ESP、WCO和静态Capon-INCM-MVDR。
smoke阶段用于筛选参数，preliminary阶段固定使用smoke锁定值，不进行二次
调参。主要评分是17个抖动点中“逐点输出SINR中位数”的最小值，预设目标
为15 dB。

本次实验没有得到“普通INCM在两种快拍条件下均最强且不低于15 dB”的
结果。该否定结果必须保留，不能通过给其他方法使用较差参数来改变排名。

## 锁定参数

两种快拍条件最终锁定了相同参数：

| 方法 | 参数 | 锁定值 |
| --- | --- | ---: |
| DL-MVDR | 相对平均SCM功率的加载系数 | 0.1 |
| ESP | 信号子空间维数 | 3 |
| WCO | 三轴等RMS离线设计抖动 | 4° |
| 静态INCM | Capon谱加载系数 | 0.01 |
| 静态INCM | 期望信号排除区半宽 | 25° |
| 静态INCM | 收缩系数 | 0 |

WCO的8°设计候选会使离线标定半径不再小于
`||aRef||=3`，因而不满足经典球形不确定集约束的可行条件。该候选已在
smoke排名表中标记为不可行；2°、4°和6°候选均正常参与比较。

## smoke筛选结果

表中数值均为17个抖动点的最低逐点中位SINR，单位为dB。

| 快拍数 | Oracle | DL-MVDR | ESP | WCO | 静态INCM |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 8 | 19.196 | 3.647 | 3.183 | 3.409 | 0.066 |
| 64 | 19.196 | 12.043 | 11.971 | 12.107 | -0.025 |

smoke样本量很小，以上数值只用于锁定参数，不能作为方法优劣结论。

## preliminary锁定验证结果

当前preliminary配置使用30次配对蒙特卡洛、每点30周期和51×51角域网格。

| 快拍数 | 方法 | 最低逐点中位SINR/dB | 全部点与周期总体中位SINR/dB |
| ---: | --- | ---: | ---: |
| 8 | Oracle | 19.349 | 19.361 |
| 8 | DL-MVDR | 5.652 | 5.824 |
| 8 | ESP | 5.518 | 5.716 |
| 8 | WCO | 5.516 | 5.734 |
| 8 | 静态INCM | 2.272 | 6.211 |
| 64 | Oracle | 19.349 | 19.361 |
| 64 | DL-MVDR | 13.087 | 13.747 |
| 64 | ESP | 13.899 | 14.073 |
| 64 | WCO | 13.064 | 13.797 |
| 64 | 静态INCM | 2.465 | 6.651 |

在8快拍条件下，静态INCM的总体中位数略高于三种实用基线，并在0°至
4°的大多数扫描点领先；但它在高抖动区快速下降，8°处中位SINR仅约
2.27 dB，因此不满足整条曲线领先或15 dB目标。在64快拍条件下，SCM质量
明显改善，DL-MVDR、ESP和WCO稳定在约13至14 dB，静态INCM在全部抖动点
均落后。

## 原因诊断

对零抖动单周期样本的检查显示，真实INCM的两个主特征值约为9460和8540，
而静态重构对应主特征值仅约69和49。Capon残差谱求和约为1460，但按0.01
方向余弦单元面积求积后，加权谱功率约为14.6，重构干扰子空间同时受到
全补角域弥散谱的影响。把干扰部分单纯放大1至1000倍只能把严格指标提高
到约0.37 dB，说明问题不仅是总体尺度偏小，还包含干扰特征方向不够集中。

因此，现有结果适合支持以下初步表述：已经完成姿态抖动场景、经典鲁棒
方法和普通静态INCM的可复现比较；普通静态INCM在有限快拍、低至中等
抖动区域出现一定趋势优势，但在高抖动和充分快拍条件下不能保持优势。
若后续需要提高INCM性能，应研究报告已规划的峰值筛选、时序稀疏增强、
局部非均匀求积和结构约束，而不是继续通过经典方法参数追调制造排名。
